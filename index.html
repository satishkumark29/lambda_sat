01. Foundation

Four Building Blocks of Functional Python

Instead of writing manual index loops, functional programming passes small, single-purpose functions directly into pipeline operations.

Anonymous Function

lambda

A compact, unnamed one-line function defined on the spot. It takes any number of arguments and returns the result of a single expression. 

# Regular vs lambda
lambda x: x * 2
# Input 4 → Returns 8
Transform Every Item

map()

Applies a lambda rule to every single item on the belt and produces a new list of the exact same length with transformed values. 

list(map(lambda x: x * 2, [1, 2, 3]))
# Output: [2, 4, 6]
Keep Passing Items

filter()

Tests each item against a True/False condition. Items returning True stay on the output belt; items returning False are rejected. 

list(filter(lambda x: x > 4, [2, 5, 8]))
# Output: [5, 8]
Combine Into One Value

reduce()

Folds items together one by one using a running accumulator (acc) until the entire list collapses into a single final result. 

reduce(lambda a, x: a + x, [1, 2, 3, 4])
# Output: 10
